# Actividad_Computacion_docker

En este repositorio se encuentra el entregable para la actividad de Computación.

1. Carpeta Java que contiene la aplicación generada con java desde un servidor linux
2. Script llamado gestor.sh con las diferentes opciones segun el documento
3. Dockerfile que se encuentra en la misma carpeta de Java para poder crear la imagen en el item 3 con exito.

recomendaciones:

Contar con Docker instalado previamente en la maquina donde se ejecute este proyecto
validar Git version para clonar el proyecto en la maquina.
